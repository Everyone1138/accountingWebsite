# Arco V&S Consulting — Colombia services expansion

This version expands the approved interactive bilingual website into a multi-page accounting site.

## New Spanish service pages
- Outsourcing contable
- Impuestos y cumplimiento tributario
- Nómina y seguridad social
- Facturación electrónica y documentos soporte
- Reportes financieros y NIIF
- Tesorería, cartera y flujo de caja
- Contabilidad y control financiero de proyectos
- Consultoría financiera y CFO externo

Each has a matching English page under `/en/services/`.

## GitHub Pages
Upload the **contents** of this folder to the repository root. `index.html` must remain at the root. Relative links are used so the project works on GitHub Pages subpaths.

## Production note
Service descriptions are written as marketing copy and should be reviewed by the firm's Colombian public accountant/tax adviser before launch, especially scope-specific tax, payroll, NIIF and compliance wording.
