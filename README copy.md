# Arco V&S Consulting — Accounting-first redesign

Static, responsive website concept built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and copy
- `styles.css` — visual design, responsive behavior, animation states
- `script.js` — scroll reveals, mobile menu, FAQ accordion, financial calculator, contact mailto form

## Preview
Open `index.html` in a browser.

For a local development server, from this folder you can run:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Notes
- The phone number and email are based on the live Arco V&S contact header available during the redesign.
- The financial dashboard values in the hero are explicitly illustrative.
- The calculator is illustrative and not accounting or tax advice.
- The contact form currently opens the visitor's email app. For production, connect it to WordPress, Formspree, a server endpoint, or your preferred CRM/form tool.
